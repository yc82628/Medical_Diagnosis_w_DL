Real retinal photos for testing the website (one eye per photo).

Source: IDRiD - Indian Diabetic Retinopathy Image Dataset
  Prasanna Porwal, Samiksha Pachade, Manesh Kokare et al., IEEE Dataport, 2018.
  Downloaded from https://zenodo.org/records/17219542 (originally IEEE Dataport)
  Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
Changes: files renamed scan_01..12; images otherwise unmodified.

These come from the held-out evaluation half: the model was never trained or
calibrated on them.

answer_key.csv gives each photo's specialist grade, what the system is expected
to answer, and the original IDRiD file name. Look at it AFTER grading, to compare.
